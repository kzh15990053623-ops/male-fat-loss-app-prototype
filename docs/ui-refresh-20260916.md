# UI 前三项优化实施记录

日期：2026-09-16

## 改动

1. **首页减负**：将体重、腰围、周进度与热量合并为一个概览；合并重复的记录入口；移除重复健康指标卡；教练建议默认显示一条，每日复盘按需展开。
2. **统一视觉**：以暖白、墨绿、细边框和留白组织页面；去掉大面积渐变、装饰圆环和厚阴影；底部导航、登录、训练、数据与个人页使用同一套配色和圆角。
3. **调整排版**：数字字体改为正常宽度的 Barlow 500/600，内嵌字体以支持离线；降低标题和数据的字重，统一辅助文字、表单标签、行高和间距。
