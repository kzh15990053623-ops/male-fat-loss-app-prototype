# 稳减 App · UI/交互优化方案 v2

> 产品：稳减（减脂与健康管理 PWA，手机端五页结构：首页/饮食/训练/数据/我的）
> 技术栈：渐进式 ES Module + 分层 CSS（tokens/base/components/pages）+ Node 静态服务 + Supabase
> 已有质量基建：Playwright 视觉回归（320×740 / 390×844 / 430×932 三档视口）、44px 触控目标、safe-area 适配、骨架屏、模块级渲染检查

---

## 一、优化方向（已与产品方确认）

| 维度 | 决策 |
|------|------|
| 品牌语言 | **淡化"实验室/实验"概念**，当前命名（今日实验/饮食实验/训练实验/数据实验/个人实验档案）偏冷、偏工具，需要转向**高级质感 + 温度感** |
| 深色模式 | 暂不做，所有改动只需验证浅色主题 |
| 产品气质 | **偏情感陪伴**：动画与微交互可以放足剂量，打卡、记录、趋势进步都应有正反馈 |
| 用户痛点 | 暂无真实用户反馈，优先级由体验专业判断驱动 |

### 设计目标

从「临床实验室」转向「**私人健康手账**」：

- 保留现有配色资产（纸色底 + 墨青 + 信号绿 + 数据字体 Barlow Condensed），这套底子本身有高级感
- 去掉"实验/SUBJECT/MODEL"这类冷冰冰的英文眉题，换成有陪伴感的中文语境
- 文案从"指令式"转向"陪伴式"（例：「今日实验」→「今天也要好好吃饭」类语感，具体文案见第四部分）
- 视觉上做减法：减少深色大卡的滥用，让留白、数字、一条好曲线成为主角

## 三、视觉优化方案

### P0 · 修复与校准（半天）

**1. 修复训练页 FAB 遮挡**
- 方案：移除 FAB，记录入口并入「本周训练安排」卡片顶部操作位
- 理由：首页已有「现在记录」快捷面板，FAB 是冗余的第三套入口，且与底导航 z-index/布局冲突

**2. 自定义开关替换原生 checkbox**
- `.toggle-row input` → `appearance: none` 纯 CSS 滑块开关（绿色轨道 + 白色滑钮 + 150ms 滑动过渡）
- 设置页所有布尔项统一使用

**3. 同步状态语义重定义**

| 状态 | 视觉 | 文案 |
|------|------|------|
| 已同步 | 绿点 | 已同步 |
| 保存中 | 橙点 + 呼吸动画 | 保存中… |
| 离线 | 灰点 | 离线，已存本机 |
| 本机账号 | 蓝灰点 | 本机模式 |
| 同步失败 | 红点 + 可点击重试 | 同步失败，点我重试 |

**4. 文字可读性校准**
- 全量辅助文字下限 0.75rem（12px）
- `--muted-2: #8a9699` → `#6f7c80`（过 AA 对比度）
- 建立字号阶梯文档：caption 12 / body 14-15 / title 17-20 / hero number 44-56

### P1 · 质感重塑（核心批次）

**5. 命名与文案去实验室化**

| 现状 | 建议 |
|------|------|
| 今日实验 | 今天 |
| 饮食实验 | 好好吃饭 |
| 训练实验 | 动起来 |
| 数据实验 | 你的进步 |
| 个人实验档案 | 我的 |
| SUBJECT / PERSONAL | 删 |
| NUTRITION / MODEL | 删或改「AI 识别」 |
| TODAY / FOCUS | 今日三件事（保留，去掉英文眉题） |

原则：英文小眉题全站从 ~10 处减到 0-2 处；数字单位（kcal/kg/cm）保留 Barlow Condensed 数据字体——高级感来自"克制的字体对比"，而不是英文装饰。

**6. 深色 hero 卡片节奏重塑（每页一种性格）**

- **首页**：保留深色 hero（门面担当），但内部重构——
  - 进度环从"和大数字挤在右上角"改为独立右列，加载时描边动画
  - 环内数据改为「本周完成度」（快节奏正反馈），总目标进度挪到「我的」页
  - 底部三格数据（剩余/摄入/消耗）拆出 hero，改为浅色 strip 卡片
- **饮食页**：AI 输入卡改浅色 + 绿色左边条；深色只留给 AI 识别结果卡（输入轻、结果重）
- **训练页**：今日 session 卡用绿色渐变（`--green → --signal`），与"运动=活力"语义挂钩，替代深蓝黑
- **数据页**：趋势解读卡保留深色（像报告封面），不动

**7. 卡片质感**
- 半透明卡片 → 实色 `--paper-2` + `--shadow-soft` 轻投影
- 细边框留给 hover/选中态表达层级
- 卡片圆角统一走 `--radius-card`，检查现存例外

**8. 空状态插画化**
- 现在空态是 dashed 边框 + 图标，偏工程感
- 改为一句话陪伴文案 + 主行动按钮（如「还没有记录，吃下第一口前先来记一笔？」）

### P2 · 品牌深化（可选）

**9. 数据字体全站统一**：所有 kcal/kg/cm/% 大数字强制 `--font-data`，排查漏网
**10. 启动/加载体验**：骨架屏已有，可给 skeleton 块加 shimmer 扫光（比静态灰块更显高级）

## 四、交互优化方案（情感陪伴主线）

### P0 · 基础反馈

**1. 页面切换过渡**：五 tab 切换加 150ms `opacity + translateY(4px)` 淡入；包在 `@media (prefers-reduced-motion: no-preference)` 内

**2. 触感反馈**：完成打卡/保存记录时 `navigator.vibrate(10)`（iOS 静默失败无副作用）

**3. 按钮反馈体系化**
- 全局 `:focus-visible`：`2px solid var(--signal)` + 2px offset
- hover 态补齐（当前仅部分按钮有）
- 主按钮加 loading 变体（内置 spinner + 文案切换），消除"点击后无反应→toast"的断档

**4. 表单体验**
- 体重/腰围输入确认 `inputmode="decimal"`
- 高频数字字段加 +/- 步进器（记录体重是每日高频操作）
- AI 识别等待期：骨架屏 + 可取消按钮

### P1 · 多巴胺时刻（情感陪伴核心）

**5. 打卡庆祝微交互**
- 「今日三件事」打勾：check 图标 scale 弹跳（cubic-bezier 回弹曲线）+ 卡片 200ms 绿色呼吸
- 三件事全部完成：轻量全屏庆祝（纸屑或光环扩散 1.2s，可跳过，每日只出现一次）

**6. 数字的生命力**
- 首页体重、剩余热量等 hero 数字：入场时 count-up 动画（300-500ms）
- 体重下降时，趋势卡数字旁边给一句动态鼓励（「这周轻了 0.8kg，很稳」）

**7. 数据页图表可交互**
- 纯 SVG 折线加 touch 悬停 tooltip（日期 + 数值），不引图表库，保持零依赖
- 折线入场描边动画（stroke-dashoffset）

**8. 连续记录的仪式感**
- 「连续记录 · DAY 3」强化为视觉资产：火焰/连击徽章，断签前一天给温柔提醒而非惩罚性提示

### P2 · 效率手势

**9. 首页下拉刷新**（touch 手势自实现，注意与 `overscroll-behavior` 协调）
**10. 长按饮食记录 → 复制到今日**（健身餐重复率极高）

## 五、文案语气指南（新增）

配合情感陪伴定位，全站文案遵循：

- **不命令**：「立即记录」→「记一笔」
- **不评判**：超支不说「超出预算」，说「今天吃得开心吗？明天轻一点就好」
- **看见努力**：完成率 50% 不说「仍有空间」，说「已经过半了」
- **失败时温柔**：同步失败给「网络开小差了，数据安全地存在本机」

## 六、工程配合

1. **视觉回归扩档**：现有三档视口基础上，补 `prefers-reduced-motion` 场景的截图基准
2. **a11y 门禁**：`npm run check` 链路中接入 axe-core，对五页做对比度/焦点/语义断言
3. **交互态收敛**：app-render.js（1103 行）/ app-actions.js（1276 行）目前健康；新增动画与交互态时，交互态 class 统一收敛到 app-state 的 UI 切片管理，避免散落的 classList 操作
4. **每批验收**：每批改动后跑 `npm run verify` + 更新视觉回归基准

## 八、风险与边界

- 所有动画必须可在 `prefers-reduced-motion` 下完全降级为无动画
- 不引入任何运行时依赖（图表库/动画库），保持当前零框架架构
- 庆祝动效克制使用：全屏级反馈每日上限一次，避免打扰变负担
- 配色资产不变，改动集中在"使用方式"，不改 token 色值（除 `--muted-2` 对比度校准）
